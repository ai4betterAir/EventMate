# EventMate

**Plan. Join. Enjoy.**

EventMate is a lightweight event management website for sports, parties, trips, BBQs, community activities and other group events.

## Current prototype

The first GitHub Pages prototype includes:

- Responsive landing page
- Event categories
- Create-event form
- Join-by-code form
- Browser-local demo event storage
- RSVP / expense / group-fund concepts in the interface
- Mobile-friendly layout

## Run locally

Open `index.html` in a browser, or serve the folder with any simple static web server.

## GitHub Pages

This project is designed to run directly from the repository root using GitHub Pages.

In GitHub, open **Settings → Pages**, then under **Build and deployment** choose:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

After saving, GitHub will publish the site at the Pages URL shown in that settings screen.
